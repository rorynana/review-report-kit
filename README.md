# 리뷰 분석 리포트 키트

올리브영·화해 리뷰를 모으고, 그 리뷰로 11쪽 분석 리포트 PDF 를 만드는 키트입니다. 리포트 구성은 표지, 01 핵심 요약, 02 한눈에 보기, 03 강점, 04 충성도, 05 키워드, 06 세그먼트, 07 성분, 08 리스크, 09 심층 이슈, 10 확인된 사실입니다. 두 단계로 씁니다.

## 1. 리뷰 모으기 (Node)

필요한 것: Node, 설치된 크롬

```
npm install
node collect.js "올리브영 상품 페이지 주소"
node collect-hwahae.js "제품명"
```

collect.js (올리브영) 가 만드는 파일
- reviews.csv : 도움순 100건 + 별점 낮은순 100건 원문. 겹치는 리뷰는 한 번만 남기고 정렬 칸에 표시. 칸은 별점, 작성일, 피부 타입, 재구매 여부, 한 달 이상 사용 여부, 본문, 정렬
- oliveyoung.json : 제품명, 대표 이미지, 전체 리뷰 수와 별점 분포, 올리브영 AI 요약(긍정·부정 비율, 강점 세 가지)

collect-hwahae.js (화해) 가 만드는 파일
- hwahae.json : 화해 별점과 리뷰 수, 별점 분포, 랭킹, 좋아요·아쉬워요 키워드 집계, 전성분(EWG·주의성분·향료)
- 화해 검색 첫 상품을 씁니다. 실행 후 찍히는 상품 이름이 내 제품이 맞는지 확인하세요. 다르면 제품명을 바꾸거나 화해 상품 번호를 넣습니다.

공통
- 크롬 창이 하나 따로 열렸다가 끝나면 닫힙니다. 원래 쓰던 크롬은 건드리지 않습니다.
- 「잠시만 기다리십시오」 확인 화면이 뜨면, 열린 크롬 창에서 확인 상자를 사람이 직접 누릅니다. 2분 기다립니다.
- 요청 사이에 1초씩 쉽니다. 올리브영 1분 안팎, 화해 10초 안팎.

## 2. 리포트 만들기 (파이썬)

필요한 것: 파이썬, playwright, pymupdf, pillow, 설치된 크롬

- build_report.py : 레이아웃과 렌더
- report_style.css : 디자인
- report_data.json : 예시 데이터(토니모리 세라마이드 모찌 토너, 2026-10-19 수집). 새 제품은 이 키 구조 그대로 값만 바꿉니다
- photos/ : 예시의 제품 사진과 포토리뷰 사진. 새 제품은 oliveyoung.json 의 image 주소로 제품 사진을 받아 같은 식으로 경로를 적습니다
- nousgirl_b64.txt : 표지 그림

디자인은 코드에 고정돼 있고, 내용은 report_data.json 하나만 바꾸면 됩니다.

실행: python build_report.py 새데이터.json 리포트.pdf  (리포트.pdf 는 전체 경로로 적습니다)

새데이터.json 은 reviews.csv, oliveyoung.json, hwahae.json 세 파일의 숫자로만 채웁니다.
