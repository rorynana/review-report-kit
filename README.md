# 리뷰 분석 리포트 키트

올리브영 리뷰를 모으고, 그 리뷰로 11쪽 분석 리포트 PDF 를 만드는 키트입니다. 두 단계로 씁니다.

## 1. 리뷰 모으기 (Node)

필요한 것: Node, 설치된 크롬

```
npm install
node collect.js "올리브영 상품 페이지 주소"
```

- 도움순 100건, 별점 낮은순 100건을 모아 실행한 폴더에 reviews.csv 로 저장합니다. 겹치는 리뷰는 한 번만 남기고 정렬 칸에 표시합니다.
- 칸: 별점, 작성일, 피부 타입, 재구매 여부, 한 달 이상 사용 여부, 본문, 정렬
- 크롬 창이 하나 따로 열렸다가 끝나면 닫힙니다. 원래 쓰던 크롬은 건드리지 않습니다.
- 「잠시만 기다리십시오」 확인 화면이 뜨면, 열린 크롬 창에서 확인 상자를 사람이 직접 누릅니다. 2분 기다립니다.
- 요청 사이에 1초씩 쉽니다. 1분 안팎 걸립니다.

## 2. 리포트 만들기 (파이썬)

필요한 것: 파이썬, playwright, pymupdf, pillow, 설치된 크롬

- build_report.py : 레이아웃과 렌더
- report_style.css : 디자인
- report_data.json : 예시 데이터(토니모리 세라마이드 모찌 토너). 새 제품은 이 키 구조 그대로 값만 바꿉니다
- nousgirl_b64.txt : 표지 그림

디자인은 코드에 고정돼 있고, 내용은 report_data.json 하나만 바꾸면 됩니다.

실행: python build_report.py 새데이터.json 리포트.pdf
